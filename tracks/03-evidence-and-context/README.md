# Assemble evidence and context

Status: deferred application outline; lessons and labs are not implemented. See the [capability map](../../README.md) and [application backlog](../../docs/plans/queue/05-consulting-applications.md).

## Goal

Supply relevant evidence with stable references and enough scope information to support consulting conclusions.

## Prerequisites

Tool exchange familiarity; synthetic event/enrichment fixture from Track 2 or a supplied starting snapshot.

## Proposed lessons

| Lesson | Coverage |
| --- | --- |
| 1. Instructions and evidence | Separate policy, task, retrieved material, and tool observations; formatting is not a security boundary. |
| 2. Search and retrieval | Compare full input, keyword search, and optional semantic snippets. |
| 3. Provenance and coverage | Stable event IDs, query/source versions, time zones, time ranges, and incomplete collection. |
| 4. State and summaries | Keep evidence references and unresolved questions outside lossy narrative summaries. |

## Proposed exercise

Produce a timeline from a synthetic event corpus with a conflicting enrichment response and a missing time interval. Attach references to every material observation and label inferences.

## Completion check

Another consultant can locate evidence for each claim and identify the collection gap. Retrieval evaluation separates missing evidence from poor interpretation.

## Scope

Teach the necessary concepts locally. External viewing is optional. Use independent starting states, synthetic fixtures, and small visible implementations. No live client access or production deployment is required.

## Original sources and project additions

[Anthropic: Effective context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) supports context selection; [Sentence Transformers semantic search](https://www.sbert.net/examples/sentence_transformer/applications/semantic-search/README.html) supplies optional retrieval examples. Claim labeling and engagement provenance requirements are project design.
